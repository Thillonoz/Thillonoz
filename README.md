## 📂 My Projects

### **Personal Projects**

*   [**Cuguru**](https://github.com/Thillonoz/cuguru) – A graphical Suguru logic puzzle game developed entirely in **C** using **Raylib**. I built a fully automated **CI/CD pipeline via GitHub Actions** to cross-compile, package, and release ready-to-play binaries (.deb, AppImage, .exe) for both Linux and Windows.
*   [**Embedded Fountain**](https://github.com/Thillonoz/embeddedfountain) – An automated, solar-powered **microcontroller-controlled fountain**. It was a hands-on opportunity to practice integrating hardware and software using an ESP32, MQTT for remote automation, and various sensors to create a tangible product.
*   [**YouTube Comment Section Enhancer**](https://github.com/Thillonoz/ytcse) – A privacy-first Chrome browser extension. It dynamically injects UI elements into YouTube to provide live comment searching, custom keyword/spoiler filtering, and persistent user blocking using local browser storage.

### **Group Projects**

*   [**Speedometer**](https://github.com/Thillonoz/speedometer) – A **Qt GUI client/server** project that demonstrates versatile communication protocols, including **TCP** (desktop), **UART** (ESP32), and **BLE** (ESP32-to-ESP32).
